## 1.0.0 - 2026-10-14

### Added

- Per-app weekly notification schedules, call and alarm exceptions, and temporary exceptions.
- Local settings backup, accent color selection, and light, dark and AMOLED themes.
- Localized the app interface in English, Brazilian Portuguese, Spanish, French, German, Italian, Japanese and Simplified Chinese.
- Added a persistent language selector in Settings, with the device language as the default.
- Localized schedule dates, manufacturer battery guidance, permission errors and GitHub update messages.
- Added English and Brazilian Portuguese versions of the project README and changelog.
- Added a GitHub Actions release workflow that validates a version tag, signs the APK, and publishes a SHA-256 checksum.

- Optionally check GitHub for app updates. Android still asks the user to confirm installation.
