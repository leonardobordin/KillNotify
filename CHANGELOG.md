## Unreleased

### Added

- Localized the app interface in English, Brazilian Portuguese, Spanish, French, German, Italian, Japanese and Simplified Chinese.
- Added a persistent language selector in Settings, with the device language as the default.
- Localized schedule dates, manufacturer battery guidance, permission errors and GitHub update messages.
- Added English and Brazilian Portuguese versions of the project README and changelog.

### Existing app capabilities

- Configure weekly notification schedules independently for installed apps.
- Allow call and alarm notifications when the sending app identifies their category, and set temporary exceptions.
- Choose light, dark or AMOLED appearance, customize the accent color, and import or export a local settings backup.
- Optionally check GitHub for app updates. The Android installer still asks the user to confirm installation.
